# CodeAlpha Stock Portfolio Tracker

An interactive paper-trading Stock Portfolio Tracker built using Python. This project allows users to buy and sell virtual shares, manage a portfolio, track transactions, simulate market price changes, and monitor stock prices.

## Features

- View available stocks and their prices
- Search stocks by symbol, company name, or sector
- Add new stocks to the simulated market
- Buy and sell shares
- View portfolio holdings
- Calculate portfolio value and profit or loss
- View transaction history
- Simulate random market price changes
- View stock price history
- View market gainers and decliners
- View portfolio by sector
- Manage a stock watchlist
- Create and manage price alerts
- Export transactions to CSV
- Reset the portfolio
- View simulated market statistics
- Save portfolio data using JSON
- Starting virtual cash of $100,000

## Technologies Used

- Python
- Random module
- JSON for saving portfolio data
- CSV for exporting transactions
- Lists and dictionaries
- Functions
- Loops and conditionals
- File handling

## How to Run

1. Install Python 3 on your system.
2. Open the project folder in VS Code.
3. Open a terminal in that folder.
4. Run the following command:

`python stock_portfolio.py`

## Gameplay

- Start the program to view the main menu
- Choose an option by entering its number
- View available stocks and their prices
- Buy shares using virtual cash
- Sell shares from your portfolio
- View your portfolio and transaction history
- Simulate a market session to change stock prices randomly
- Track stock price history and market movements
- Manage your watchlist and price alerts
- Export transactions to a CSV file
- Save your portfolio before exiting

## Notes

This project is a beginner-friendly Python application created for the CodeAlpha Python Programming Internship. It uses simulated stock prices and does not connect to a real stockbroker or provide live market data or investment advice.
